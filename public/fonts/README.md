# Domaine Display Font Assets

This directory holds the licensed webfont assets for **Domaine Display** by [Klim Type Foundry](https://klim.co.nz/fonts/domaine-display/).

## Supported Filenames
Place your official Klim `.woff2` (or `.woff`) files here:

### Retail / Commercial Licence:
- `DomaineDisplay-Regular.woff2` (Default Regular 400 heading weight)
- `DomaineDisplay-RegularItalic.woff2`
- `DomaineDisplay-Medium.woff2`
- `DomaineDisplay-Bold.woff2`

### Evaluation / Test Font Licence:
If evaluating with Klim's official test package from [klim.co.nz/test-fonts/](https://klim.co.nz/test-fonts/):
- `TestDomaineDisplay-Regular.woff2`
- `TestDomaineDisplay-RegularItalic.woff2`
- `TestDomaineDisplay-Medium.woff2`
- `TestDomaineDisplay-Bold.woff2`

## CSS Variable
```css
--font-display: 'Domaine Display', serif;
```
Tailwind utility class: `font-display`
