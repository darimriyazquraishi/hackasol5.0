# TEAM NAME- Honeybuns

TRACK NAME - Open Innovation

SOLUTION NAME- LUMI (Local Unified Multimodal Intelligence)

PROBLEM STATEMENT - Companies Such as Refineries, PSUs, defence units, and government offices handle highly confidential data &  handle sensitive documents. This leaves employees to perform tedious task manually making work slow and inefficient or use cloud ai models that may send this sensitive data to external third party servers.

OUR SOLUTION- LUMI(Local Unified Multimodal Intelligence) is an agentic ai workbench that works completely offline to help execute and automate tedious tasks of employees in companies that deals with sensitive information.

EXISTING SOLUTIONS AND HOW LUMI IS DIFFERENT- NVIDIA AI Enterprise, Cloudera AI, Red Hat OpenShift AI, AnythingLLM, Dify, and Open WebUI offer enterprise AI infrastructure, private AI, local RAG, or agent workflows, whereas LUMI differentiates itself by integrating sovereign on-premise multimodal AI, intelligent model routing, human-approved dynamic workplans, specialized multi-agent execution, sandboxed tools, and validated native Office deliverables into one end-to-end task-execution platform.

WHO IT TARGETS- Enployees of companies such as Refineries, PSUs, defence units, and government offices etc. We seek to make their job easier and safer by giving them a completely free agentic AI workbench.

FEATURES- 
Frontend layer: A chatbot for responding to users which also functions as an intent and capability router.
Intent & Capability router: Extracts user request from the prompt and decides the relevant models it'll need to call to fulfill the task.
Workplan Generation: The system's proposed solution and exectuion sequence is hown to the user such that they can review it, approve it, edit it or reject it.

The models included in the system are-
Image Generation Model: Creates an image according to user request.
Reasoning and Synthesis: Generates summaries, explanation and deliverables (pdf, excel sheet, ppt etc.)
Vision Agent: Extracts text from uploaded images and pdfs and calls reasoning agent to fullfill user request.
Math and Coding Agent: Performs engineering task that contains math calculation and along with coding task too.
Vector RAG agent: Contains companies guidelines according to which deliverables are designed.
IDE workspace: A dedicated workspace for coding and handling coding projects with collaboration of coding agents.
