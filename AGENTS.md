# Project Agent Instructions & Quality Rules

## Mandatory Skill: Impeccable Design Quality
- The **`impeccable`** skill (`.agents/skills/impeccable/SKILL.md`) is installed in this project.
- **Rule:** Always use and consult `impeccable` on any design, UI/UX, styling, layout, component, or frontend enhancement in this project.
- **Pre-Response Check:** Whenever you do any work and reply to the user, ALWAYS first check and verify whether the task is completely done and satisfies all requirements before replying.

## Mandatory Rule: Always Build
- Whenever any code, component, server, or script is modified, ALWAYS run and verify `npm.cmd run build` before finishing the task so production build artifacts in `dist/` are always fresh and error-free.
